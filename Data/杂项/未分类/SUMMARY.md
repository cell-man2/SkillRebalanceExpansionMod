## 神通

### `重做` 共劫化生阵

**标签**：`杂项未分类`/`共劫化生阵`

**品阶**：天阶中

**属性**：阵法、木

**消耗**：4\*`木`+4\*`同`

**悟道需求**：阵（融会贯通）、木（融会贯通）

**获取途径**：海外拍卖会（南崖岛、碎星岛）

| 层级   | 效果                                                         |
| ------ | ------------------------------------------------------------ |
| 炼气期 | 【阵法】双方受到技能伤害时，将伤害的20%转嫁给对方；每因此转移18点伤害使你获得18点临时血量上限。 |
| 筑基期 | 【阵法】双方受到技能伤害时，将伤害的20%转嫁给对方；每因此转移27点伤害使你获得27点临时血量上限。 |
| 金丹期 | 【阵法】双方受到技能伤害时，将伤害的20%转嫁给对方；每因此转移42点伤害使你获得42点临时血量上限。 |
| 元婴期 | 【阵法】双方受到技能伤害时，将伤害的20%转嫁给对方；每因此转移75点伤害使你获得75点临时血量上限。 |
| 化神期 | 【阵法】双方受到技能伤害时，将伤害的20%转嫁给对方；每因此转移300点伤害使你获得300点临时血量上限。 |

**驱阵消耗**：1\*`木`+1\*`同`+1\*`同`

**驱阵属性**：气、木

| 层级   | 驱阵效果                             |
| ------ | ------------------------------------ |
| 炼气期 | 【后继无力】驱动一次【共劫化生阵】。 |
| 筑基期 | 【后继无力】驱动一次【共劫化生阵】。 |
| 金丹期 | 【后继无力】驱动一次【共劫化生阵】。 |
| 元婴期 | 【后继无力】驱动一次【共劫化生阵】。 |
| 化神期 | 【后继无力】驱动一次【共劫化生阵】。 |
