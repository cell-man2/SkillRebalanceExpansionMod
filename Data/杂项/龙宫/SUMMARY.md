## 功法

### `修改` 太上化龙真诀

**标签**：`杂项龙宫`/`太上化龙真诀`

**品阶**：天阶上

**属性**：体

**悟道需求**：体道达到融会贯通

**获取途径**：龙宫化龙池剧情

**兑换途径**：龙宫功法第二次交付龙鳞后（1000000灵石）

| 层级   | 修炼速度 | 效果                                                    |
| ------ | -------- | ------------------------------------------------------- |
| 第一层 | 864      | 每回吸收灵气增加X（X为当前回合数，吸收灵气上限为2）。   |
| 第二层 | 1728     | 每回吸收灵气增加X（X为当前回合数，吸收灵气上限为4）。   |
| 第三层 | 2592     | 每回吸收灵气增加2X（X为当前回合数，吸收灵气上限为6）。  |
| 第四层 | 3456     | 每回吸收灵气增加2X（X为当前回合数，吸收灵气上限为8）。  |
| 第五层 | 4320     | 每回吸收灵气增加3X（X为当前回合数，吸收灵气上限为10）。 |

| 金丹期 | 消耗【真龙之血】\*1获得【龙怒】\*1；每场战斗限一次。 |
| 元婴期 | 消耗【真龙之血】\*1获得【龙怒】\*1；每场战斗限一次。 |
| 化神期 | 消耗【真龙之血】\*1获得【龙怒】\*1；每场战斗限一次。 |
