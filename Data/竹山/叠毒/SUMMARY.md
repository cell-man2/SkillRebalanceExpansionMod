## 功法

### `修改` 血毒经

**标签**：`竹山叠毒`/`血毒经`

**属性**：木

**悟道需求**：木（融会贯通）

| 层级   | 修炼速度 | 效果                                                         |
| ------ | -------- | ------------------------------------------------------------ |

| 第二层 | 2160     | 【中毒】触发时，恢复28点生命值，若触发角色为你则额外移除【中毒】\*2；回合开始时，若没有【中毒】则获得【中毒】\*1。 |
| 第三层 | 3240     | 【中毒】触发时，恢复70点生命值，若触发角色为你则额外移除【中毒】\*5；回合开始时，若没有【中毒】则获得【中毒】\*1。 |
| 第四层 | 4320     | 【中毒】触发时，恢复140点生命值，若触发角色为你则额外移除【中毒】\*10；回合开始时，若没有【中毒】则获得【中毒】\*1。 |
| 第五层 | 5400     | 【中毒】触发时，恢复420点生命值，若触发角色为你则额外移除【中毒】\*30；回合开始时，若没有【中毒】则获得【中毒】\*1。 |

## 神通

### `修改` 青蛇劲

**标签**：`竹山叠毒`/`青蛇劲`

**品阶**：地阶上

**属性**：木

**消耗**：3\*`木`+1\*`同`

**悟道需求**：木（略有小成）

**请教途径**：竹山叠毒NPC（炼气后期及以上）

**兑换途径**：竹山宗秘阁（20沧元丹）

| 层级   | 效果                                                  |
| ------ | ----------------------------------------------------- |
| 炼气期 | 敌方获得【中毒】\*2；【同】敌方额外获得【中毒】\*1。  |
| 筑基期 | 敌方获得【中毒】\*3；【同】敌方额外获得【中毒】\*2。  |
| 金丹期 | 敌方获得【中毒】\*4；【同】敌方额外获得【中毒】\*3。  |
| 元婴期 | 敌方获得【中毒】\*6；【同】敌方额外获得【中毒】\*4。  |
| 化神期 | 敌方获得【中毒】\*10；【同】敌方额外获得【中毒】\*5。 |
