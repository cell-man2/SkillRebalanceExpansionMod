# SkillRebalanceExpansionMod

这是一个我个人自用的《觅长生》功法、神通加强与扩展模组，算是第二个C#练手作，按照我的需求编写的工厂方便快速实现对原版神通功法效果调整（Next的文件夹结构让我不太喜欢）。主要内容是对原版我看的不爽的内容加强，不过数值上会有所控制，至少不会比五行剑强（大概）。

本项目的改动以个人游玩体验为主要标准，简单来说就是一时兴起想到哪改哪。由于个人色彩比较重就不发到创意工坊了，

## 项目结构

- `Data`：实际的流派、杂项和模板数据。
- `Docs`：自定义内容的编写指南（如果喜欢本项目可以自行下载源码后按照个人需求修改）。
- `Models`：各类游戏内容的数据定义。
- `Factories`：各类内容的创建与注册逻辑。
- `Core`、`Patches`、`Utils`：加载、补丁和通用工具代码。
- `Archive`：早期编写示例和已归档的参考代码，编写工厂通过后留档的最小补丁案例。
